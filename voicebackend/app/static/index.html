REQUEST FLOW
From a spoken detail to an editable draft.
The mobile app talks to this service; language processing goes through Bhashini, while catalogue decisions use transparent backend rules.

            

              
01
Capture & validate
Send text or a mono WAV, FLAC or MP3 recording with a selected source language. Upload size, format and duration are checked.

              
02
Transcribe & translate
Bhashini returns the original transcript and Hindi and English translations. Its model IDs and credentials stay on the server.

              
03
Extract & clarify
Keyword dictionaries and patterns identify product fields. Missing values stay empty and become guided questions.

              
04
Review the draft
Controlled templates create descriptions. The draft is saved and every extracted field can be edited before publishing elsewhere.

            

            
Testing without credentials
Health, languages, validation, list and read operations work locally. ASR and translation calls need the values in voicebackend/.env. The sample output on this page is illustrative and never substituted for a live API response.
